# 🥋 작은 격투

옆에서 보는 1:1 대전 격투. 컴퓨터 파이터 **5명**을 차례로 이겨요. 3판 2선승, 한 판은 60초.

## 조작
| | 폰 | PC |
|---|---|---|
| 이동 | ◀ ▶ | ← → (A D) |
| 점프 | ⤒ | ↑ (W) |
| 약공격 👊 | 버튼 | J (Z) |
| 강공격 💥 | 버튼 | K (X) |
| 막기 🛡 | 누르고 있기 | L (C, ↓) |
| 필살기 ✨ | 기가 가득 찼을 때 | U (V, 스페이스) |
| 대시 | ◀ ▶ 를 같은 방향으로 빠르게 두 번 | ← ← 또는 → → |

## 규칙
- **약공격**은 빠르고 약하고, **강공격**은 느리고 세고 빈틈이 커요.
- **막기**를 누르고 있으면 피해가 거의 없어요. 하지만 막을 때마다 **가드 게이지**가 차고, 가득 차면 가드가 깨져서 잠시 못 움직여요. 공중에서는 막을 수 없어요.
- **파이터 3명** 중 고르고(처음 화면), 체력·속도·세기와 **필살기**가 달라요: 🥋 도장 제자(고르게, 기파) · 🥷 번개 닌자(빠르고 약함, 돌진 펀치) · 🐻 철권 곰(느리고 튼튼, 승룡).
- 때리면 **기**가 차요(맞아도 조금). 가득 차면 **필살기**: 🥋 기파(멀리 날아가요, 점프로 피함) · 🥷 돌진(앞으로 달려 침, 빗나가면 빈틈이 커요) · 🐻 승룡(위로 솟으며 올려침, 솟는 동안 무적이라 점프해 덤비는 상대를 격추).
- **타격 멈춤**: 때리는 순간 화면이 잠깐 멈추고 흔들려요(세게 칠수록 길게). 멈추는 동안 누른 버튼도 기억해요.
- **연계**: 약공격이 맞으면 바로 약 → 약 → 약, 약 → 강으로 이어져요(빗나가면 안 돼요). 필살기도 맞히고 이어 쓸 수 있어요.
- **대시**: 앞으로는 빠르게 파고들고(도중에 공격 가능), 뒤로는 처음 잠깐 **무적**이에요. 땅에서만 돼요.
- 연타(콤보)는 맞을수록 피해가 줄어서 끝없이 이어지지 않아요.
- 시간이 끝나면 체력이 더 많이 남은 쪽이 이겨요. 딱 같으면 둘 다 1점.
- 상대: 🐣 꼬마 → 🐗 돌진이(돌진 필살) → 🐢 거북이(승룡 필살) → 🐇 날쌘돌이(기파 필살, 대시) → 🦁 대장(셋 다). 각자 성격과 **무대**가 달라요(마당·대숲·연못·밤 지붕·대장 도장).

## 만든 방식
- `logic.js` — DOM 없는 규칙 (`LOGIC_FT`). 1/60초 한 칸씩 진행하고 같은 입력이면 항상 같은 결과. 기술(준비·맞는 구간·빈틈), 막기·가드, 기파, 라운드, 컴퓨터 상대(AI) 포함.
- `game.js` / `index.html` — 그리기(선으로 그린 파이터, 확대하는 카메라), 입력(폰 버튼 멀티터치·키보드), 소리.
- 시험: `node --test` (디렉터리). 규칙, 막기·가드, 기파, 라운드 흐름, 컴퓨터 상대, 그리고 **사람처럼 싸우는 봇**으로 상대가 순서대로 강해지는지도 확인합니다 (`test/bot.js`).
- 저장: `ftLevel`(다음 상대), `ftBest`(이긴 상대 수), `ftHero`(고른 파이터), `ftSound`.

정적 파일만으로 돌아갑니다 (서버 불필요).
