# 🥋 작은 격투

옆에서 보는 1:1 대전 격투. 컴퓨터 파이터 **5명**을 차례로 이겨요. 3판 2선승, 한 판은 60초.

## 조작
| | 폰 | PC |
|---|---|---|
| 이동 | ◀ ▶ | ← → (A D) |
| 점프 | ⤒ | ↑ (W) |
| 약공격 👊 | 버튼 | J (Z) |
| 강공격 💥 | 버튼 | K (X) |
| 막기 🛡 | 누르고 있기 | L (C, ↓) |
| 필살기 ✨ | 기가 가득 찼을 때 | U (V, 스페이스) |

## 규칙
- **약공격**은 빠르고 약하고, **강공격**은 느리고 세고 빈틈이 커요.
- **막기**를 누르고 있으면 피해가 거의 없어요. 하지만 막을 때마다 **가드 게이지**가 차고, 가득 차면 가드가 깨져서 잠시 못 움직여요. 공중에서는 막을 수 없어요.
- 때리면 **기**가 차요(맞아도 조금). 가득 차면 **필살기**: 앞으로 날아가는 기파예요. 막을 수 있고, **점프로 피할 수 있어요**.
- 연타(콤보)는 맞을수록 피해가 줄어서 끝없이 이어지지 않아요.
- 시간이 끝나면 체력이 더 많이 남은 쪽이 이겨요. 딱 같으면 둘 다 1점.
- 상대: 🐣 꼬마 → 🐗 돌진이 → 🐢 거북이 → 🐇 날쌘돌이 → 🦁 대장. 각자 성격이 달라요.

## 만든 방식
- `logic.js` — DOM 없는 규칙 (`LOGIC_FT`). 1/60초 한 칸씩 진행하고 같은 입력이면 항상 같은 결과. 기술(준비·맞는 구간·빈틈), 막기·가드, 기파, 라운드, 컴퓨터 상대(AI) 포함.
- `game.js` / `index.html` — 그리기(선으로 그린 파이터, 확대하는 카메라), 입력(폰 버튼 멀티터치·키보드), 소리.
- 시험: `node --test` (디렉터리). 규칙, 막기·가드, 기파, 라운드 흐름, 컴퓨터 상대, 그리고 **사람처럼 싸우는 봇**으로 상대가 순서대로 강해지는지도 확인합니다 (`test/bot.js`).
- 저장: `ftLevel`(다음 상대), `ftBest`(이긴 상대 수), `ftSound`.
